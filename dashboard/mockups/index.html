Jarvis Mind Dashboard — Phase A Mockups

Three candidate themes for the live "peer inside the mind" view. Each runs the same scripted scenario (ambient voice chatter → wake word → thinking trace → tool call → streamed reply) so you can compare feel, not content. Click through, watch a few turns, then pick a direction (or a hybrid). Data is fake — wired to shared/fake-mind.js.
